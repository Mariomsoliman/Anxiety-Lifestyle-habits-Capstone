# My anaxiety analysis

This folder contains a copy of my CS156 machine-learning assignment on forecasting tomorrow’s anxiety from my daily journal. The original project remains in my CS156-Machine-Learning repository.

## Files

- [anxiety_pipeline.ipynb](anxiety_pipeline.ipynb): the full analysis, including saved tables and figures.
- `build_notebook.py` and `interpretations.py`: the notebook source and written interpretations.
- `requirements.txt`: pinned package versions.
- `data/raw/mariams_anxiety_raw.csv`: the source CSV.
- `data/processed/anxiety_clean.csv`: the cleaned table, regenerated by the notebook.

## Run the notebook

Use Python 3.11 and run these commands from this folder:

```bash
python -m pip install -r requirements.txt
```

Open `anxiety_pipeline.ipynb` in a Jupyter-compatible notebook editor, select the Python environment with those packages installed, and run the cells in order. Keep the notebook working directory set to this folder so its relative data paths resolve.

Running `build_notebook.py` recreates the notebook source and clears execution outputs; execute the notebook afterward to restore them. The saved notebook can be read without rebuilding it.

This is a separate copy. Changes here and changes in the original repository do not automatically synchronize.
